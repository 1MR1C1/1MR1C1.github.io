Privacy Policy

MR C Uploads · last updated 13 October 2026

MR C Uploads is a personal program used by one person — me, its author — to publish my own music to YouTube channels that I own. It has no other users, no sign-up, and no server. It runs on my own computer. This policy explains exactly what it accesses and what happens to that information.

The Google permissions it asks for

When I sign in, the tool asks Google for these three permissions and no others:

  • https://www.googleapis.com/auth/youtube.upload
    Used to upload my own finished video files to my own channel.
  • https://www.googleapis.com/auth/youtube
    Used to set the title, description, tags, category, language and publish time on videos I have uploaded, and to create playlists on my channel and add my own videos to them.
  • https://www.googleapis.com/auth/youtube.force-ssl
    Used to upload subtitle files to my own videos, and to read back my own channel's list of videos so I can see which are live, scheduled or still drafts.

What it does with that access

It reads and changes only my own channels and my own videos. It never reads, changes or collects anything belonging to another person, another channel or another viewer.

It does not read comments, subscriber details, viewer identities, watch history or any analytics about the people who watch the videos.

What is stored, and where

  • A Google sign-in token is saved in a private folder on my own computer, so that I do not have to sign in every time I use the tool. It never leaves that computer and is never included in any backup that is shared or published.
  • The video files, titles, descriptions and artwork are my own work, kept on my own computer.
  • Nothing is uploaded to any server belonging to this tool, because there is no such server.

What is shared with others

Nothing. No data of any kind is sold, rented, published, or passed to any other person, company, advertiser or analytics service. The only party the tool communicates with is Google, in order to carry out the actions above on my own channels.

Keeping it, and removing it

The sign-in token is kept only while I am using the tool, and is replaced whenever it expires. I can revoke the tool's access at any time from Google Account permissions, which immediately ends all access. Deleting the saved token file from my computer has the same effect locally.

Changes

If what the tool does ever changes, this page is updated to match, and the date at the top changes with it.

Contact

This tool has one user, who is also its author, so there is nobody else whose data could be involved. Any question about it can be raised through the contact address shown on the Google consent screen when the tool asks for permission.
